## StoreDB - Database Scripts
SQL scripts for creating, configuring, and populating the `StoreDB` database.

## Requirements
- SQL Server
- SQL Server Management Studio (SSMS) or any compatible SQL client
- Permission to create databases

## Scripts
`01-storedb-init-script.sql` 
Creates the `StoreDB` database and its tables

`02-storedb-seed-status-tables.sql` 
Inserts the initial category and product status data.

`03-storedb-seed-test-data.sql` 
Inserts sample data for development and testing.

## Database Setup
The scripts must be executed in order according the number in the script's names
